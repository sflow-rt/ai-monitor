# AI Monitor

Monitor AI / ML fabric for congestion events

## To install

1. [Download sFlow-RT](https://sflow-rt.com/download.php)
2. Run command: `sflow-rt/get-app.sh sflow-rt topology`
4. Run command: `sflow-rt/get-app.sh sflow-rt ai-monitor`
5. Restart sFlow-RT

For documentation, tutorials, and community support, visit:
https://sFlow-RT.com
